# CLI・入出力仕様

`main.c` が担う起動時のモード分岐、REPL(対話モード)、および入出力の扱いを定義する。
利用者向けの使用例は [README.md](../README.md) を参照。

実行ファイル名は `calc-pgm`(Makefile の `TARGET`)。

## 起動時のモード分岐

`argc > 1` のとき `argv[1]` でモードを選択する。いずれにも該当しない場合は
標準エラーに `不明なオプション` と使用法を出力し、終了コード `1` を返す。
引数が無い(`argc == 1`)場合は REPL を起動する。

| オプション | モード | 必要な引数数 | 動作 |
|------------|--------|--------------|------|
| `-h` / `--help` | ヘルプ | — | `print_help()` を表示し `0` で終了 |
| `-e <式>` | 式評価 | `argc >= 3` | 式を評価し結果を表示 |
| `-b <式>` | ビット演算 | `argc >= 3` | 式を評価し結果を表示(`-e` と同じ処理) |
| `-l <式>` | 対数一括 | `argc >= 3` | 式を評価し ln / log2 / log10 を表示 |
| `-f <形式> <式>` | 書式指定 | `argc >= 4` | `argv[2]` の形式で結果を表示 |
| `-u <値> <前> <後>` | 単位変換 | `argc >= 5` | `conv(値, 前, 後)` を評価 |
| `-t` | 型一覧 | — | `print_types()` |
| `-s <文字列>` | 文字サイズ | `argc >= 3` | `print_size(argv[2])` |
| `-c` | 文字コード一覧 | — | `print_encodings()` |

- 引数数が不足する場合は各モードの使用法を標準エラーに出力し `1` を返す。
- 使用法メッセージ内のコマンド名は `calc` 表記(実行ファイル名 `calc-pgm` とは異なる)。

## 式引数の組み立て

`-e` / `-b` / `-l` は `argv[2]` 以降、`-f` は `argv[3]` 以降を**単一スペースで連結**して 1 つの式にする。
これによりクォートせずに `-e 1 + 2` のように渡せる。

- バッファ長は `MAX_INPUT`(1024 バイト)。超過分は切り詰められる。
- `-u` は `snprintf` で `conv(argv[2], argv[3], argv[4])` の文字列を組み立てる。
  1024 バイトを超えるとエラー(`式が長すぎます`)。

## 書式指定モード `-f` の追加規則

- `argv[2]` は `dec` / `hex` / `oct` / `bin` / `all` のいずれか。それ以外は標準エラーに
  `不明な形式` を出力し `1` を返す。
- 評価結果が浮動小数点で、形式が `hex` / `oct` / `bin` の場合はエラー
  (`hex/oct/bin は整数のみ対応`)。`dec` / `all` は許可。

## REPL(対話モード)

引数なしで起動するとバナーを表示し、以下のループに入る。

1. プロンプト `> ` を表示(`stdout` を `fflush`)。
2. `fgets` で 1 行読み込む。EOF(Ctrl-D)なら終了。
3. 末尾の改行・空白(`\n` `\r` ` ` `\t`)を除去し、先頭の空白を読み飛ばす。
4. 空行は無視して次の入力へ。
5. コマンド分岐(下表)。いずれでもなければ式として評価する。
6. 評価成功時は結果を表示し、`prev`(`_` トークンが返す直前の結果)を更新する。

| 入力 | 動作 |
|------|------|
| `quit` / `exit` | ループを抜けて終了 |
| `help` | `print_help()` |
| `types` | `print_types()` |
| `enc` | `print_encodings()` |
| `size <文字列>` | `print_size()`。引数が空なら使用法を表示 |
| その他 | `calc_eval()` で式評価 |

終了時は `終了します。` を表示し、終了コード `0` を返す。

## 入出力の経路

| ストリーム | 引数モード | REPL |
|------------|-----------|------|
| **stdout** | 計算結果(`print_result` 等) | バナー・プロンプト・結果・エラーすべて |
| **stderr** | エラー・使用法メッセージ | (使用しない) |

- 引数モードでは結果を `stdout`、エラー・使用法を `stderr` に分離する。
- REPL では評価エラーも `stdout` に `  エラー: …` として出力する(`stderr` は使わない)。
- `print_result` の各行は先頭 2 スペース。引数モードでは結果の後に空行を 1 行追加する。

## 終了コード

| コード | 条件 |
|--------|------|
| `0` | 正常終了(REPL 終了、`-h`/`-t`/`-c` など、引数モードの評価成功) |
| `1` | 引数不足・不明オプション・不明な形式・評価エラー(いずれも引数モード) |

REPL は評価エラーが起きても継続し、最終的に常に `0` を返す。
