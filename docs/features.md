# 機能仕様

各機能の正確な仕様(引数・戻り値の型、整数/浮動小数点の扱い、エラー条件、境界値)を定義する。
利用者向けの使い方・出力例は [README.md](../README.md) を参照。

戻り値はすべて `Value` 型で、整数 (`int64_t`) か浮動小数点 (`double`) を `is_float` で区別する
(→ [architecture.md](architecture.md#value-型))。桁溢れ時は `warn` フラグが立つ。

## 数値リテラル

| 形式 | 例 | 内部型 | 実装 |
|------|----|--------|------|
| 10進整数 | `42` | `int64_t` | `strtoll` (base 10) |
| 16進 | `0xFF` / `0XFF` | `int64_t` | `strtoull` (base 16) |
| 2進 | `0b1010` / `0B1010` | `int64_t` | 1 ビットずつ構築 |
| 8進 | `0o52` / `0O52` | `int64_t` | `strtoull` (base 8) |
| 浮動小数点 | `3.14`, `1e10` | `double` | 数字列の後に `.` `e` `E` があれば `strtod` |
| 前回の結果 | `_` | 直前の `Value` | REPL の `prev`(引数モードでは `0`) |

- 負のリテラルは単項 `-`(演算子)として解釈される。純粋な字句ではない。
- 各基数リテラルは接頭辞直後に桁が無い場合エラー(例: `0x` 単体 → `16進数の桁がない`)。

## 演算子

すべての二項演算はオペランドの型により整数演算/浮動小数点演算を切り替える。
整数同士の演算はオーバーフローを検出し、溢れた場合は `double` に切り替えて `warn` を立てる。

| 演算子 | 型制約 | 戻り値 | 主なエラー・境界 |
|--------|--------|--------|------------------|
| `+` `-` | 制約なし | int 同士は int(溢れたら double+warn)、float 混在は double | — |
| `*` | 制約なし | 同上 | — |
| `/` | 制約なし | int 同士で割り切れれば int、割り切れなければ double。float 混在は double | ゼロ除算エラー。`INT64_MIN / -1` は double+warn |
| `%` | **整数のみ** | int | float はエラー(`% は整数のみ`)、ゼロ除算エラー |
| `**` | 制約なし | 下記参照 | — |
| 単項 `-` | 制約なし | int は符号反転(`INT64_MIN` は double+warn)、float は符号反転 | — |
| 単項 `+` | 制約なし | オペランドをそのまま返す | — |
| 単項 `~` | **整数のみ** | int(ビット反転) | float はエラー(`~ は整数のみ`) |
| `&` `\|` `^` | **整数のみ** | int | float はエラー(`… は整数のみ`) |
| `<<` `>>` | **整数のみ** | int | float はエラー(`シフトは整数のみ`)。シフト量は `0〜63`、範囲外はエラー |

### べき乗 `**`

- 右結合。指数側は単項演算子を許容(`2 ** -1` 可)。
- `base`・`exp` がともに整数で `exp >= 0`: オーバーフロー検出付き整数べき乗。溢れたら double+warn。
- `exp == 0`: 常に `1`(整数)。
- `exp < 0`(整数同士): `double` で計算。
- どちらかが float: `pow()` により `double`。

### シフト `<< >>`

- シフト量 `r` は `0 <= r <= 63` のみ有効。範囲外(負値/64以上)は `シフト量が範囲外 (0〜63)`。
- 左オペランドを `uint64_t` にキャストして論理シフト(右シフトはゼロ埋め)し、`int64_t` に戻す。

### 演算子優先順位(低→高)

```
| → ^ → & → <<,>> → +,- → *,/,% → 単項(-,+,~) → **(べき乗) → 一次式
```

詳細は [parser.md](parser.md) を参照。

## 対数関数

| 関数 | 意味 | 実装 |
|------|------|------|
| `log(x)` | 自然対数(底 e) | `log()` |
| `log2(x)` | 2 を底とする対数 | `log2()` |
| `log10(x)` | 10 を底とする対数 | `log10()` |

- 引数は任意の式。`to_d(x) > 0` が必須。0 以下はエラー(`対数の引数は正の数が必要`)。
- 戻り値は**常に `double`**(整数を渡しても float 表示)。

## 表示変換関数

| 関数 | 設定される `fmt` | 表示 |
|------|------------------|------|
| `dec(式)` | `FMT_DEC` | `= N`(10進のみ) |
| `hex(式)` | `FMT_HEX` | 16進のみ |
| `oct(式)` | `FMT_OCT` | 8進のみ |
| `bin(式)` | `FMT_BIN` | 2進のみ |

- 引数は任意の式。**整数のみ**受け付け、float はエラー(`変換関数は整数のみ`)。
- 値は変えず表示形式のみ設定する。結果を別の演算と組み合わせると `FMT_ALL` に戻る
  (→ [architecture.md](architecture.md#value-型))。

## 単位変換関数

引数は任意の式。結果は `FMT_DEC`(`= N` 表示)。整数で割り切れる場合は整数、それ以外は `double` を返す。
乗数 `mul` は各カテゴリの基準単位への換算値。

### データサイズ(基準: バイト, `cat=0`)

| 関数 | mul | 関数 | mul |
|------|-----|------|-----|
| `b` | 1 | | |
| `kib` | 1024 | `kb` | 1000 |
| `mib` | 1024² | `mb` | 1000² |
| `gib` | 1024³ | `gb` | 1000³ |
| `tib` | 1024⁴ | `tb` | 1000⁴ |

### 周波数(基準: Hz, `cat=1`)

| 関数 | mul |
|------|-----|
| `hz` | 1 |
| `khz` | 1000 |
| `mhz` | 1000² |
| `ghz` | 1000³ |

### 時間(基準: 秒, `cat=2`)

| 関数 | mul |
|------|-----|
| `ns` | 1e-9 |
| `us` | 1e-6 |
| `ms` | 1e-3 |
| `sec` | 1 |

### 単位間変換 `conv(値, 変換前単位, 変換後単位)`

- 計算式: `値 × from_mul ÷ to_mul`(`double`)。
- 変換前・変換後は `TK_FUNC_UNIT`(上記の単位)でなければならない。
- **同一カテゴリのみ**変換可。カテゴリ(`cat`)が異なるとエラー(`単位のカテゴリが異なる`)。
- 入力が整数で結果が割り切れる場合は整数(`FMT_DEC`)、それ以外は `double`。
- 基準単位トークン `b` / `hz` / `sec` は変換先として使用可能。

## 桁溢れ警告

`double` の整数表現精度上限(2^53)超過、または整数演算のオーバーフロー時に `warn` フラグが立ち、
`print_result()` が結果に続けて `* 計算結果が桁溢れしています` を表示する。
発生源: `+ - * / ** 単項-`(整数演算)および 2^53 超えの浮動小数点結果。
